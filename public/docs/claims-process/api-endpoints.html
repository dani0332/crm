🔐 Permission System

Core Permissions

  • CLAIM_LIST: View claims listing
  • CLAIM_CREATE: Create new claims
  • CLAIM_EDIT: Edit existing claims
  • CLAIM_SHOW: View individual claims
  • CLAIMS_EXPORT_DATA: Export claim data

Status Management

  • CLAIMS_STATUS_UPDATE: Update main claim status
  • CLAIMS_SUB_STATUS_UPDATE: Update claim sub-status
  • CLAIM_EDIT: Update claim details and information

Document Permissions

  • CLAIM_DOCUMENT_UPLOAD: Upload claim documents
  • CLAIM_DOCUMENT_DELETE: Delete claim documents
  • CLAIM_DOCUMENT_S3_URL: Get S3 temporary URLs
  • CLAIM_DOWNLOAD_ALL_DOCUMENTS: Bulk document download

Permission Implementation

  • Middleware: Route-level permission checks
  • Frontend: useCan() composables for UI rendering
  • Backend: Service-level permission validation
  • Database: Role-based access control

📝 Request/Response Formats

Standard Response Format

{ "success": true, "data": { // Response data }, "message": "Operation completed successfully" }

Error Response Format

{ "success": false, "message": "Error description", "errors": { "field_name": ["Validation error message"] } }

Pagination Format

{ "data": [...], "links": { "first": "url", "last": "url", "prev": null, "next": "url" }, "meta": { "current_page": 1, "per_page": 15, "total": 100 } }

⚙️ Current Implementation Details

ClaimsController Methods

  • index(): Claims listing with 18+ filterable fields
  • create(): Show claim creation form with dropdown data
  • store(): CPAPI integration for claim creation only
  • show(): Display claim with all relationships
  • edit(): Show claim editing form
  • update(): Update existing claim
  • searchPolicies(): Internal policy search (not CPAPI)

ClaimsService Implementation

  • getClaimsData(): Main listing with filtering and pagination
  • createClaim(): CPAPI integration with 15+ data fields
  • searchActivePolicies(): Internal PersonalQuote queries
  • updateClaimStatus(): Status updates with Activity logging
  • sendNotification(): AI-optimized messaging
  • uploadClaimDocuments(): Azure S3 document management

Request Validation Classes

  • ClaimStoreRequest: Initial claim creation validation
  • ClaimUpdateRequest: General claim update validation
  • ClaimDetailsUpdateRequest: LOB-specific details validation
  • ClaimStatusUpdateRequest: Status transition validation
  • SearchPoliciesRequest: Policy search validation
  • ClaimSendNotificationRequest: Notification validation

Observer Pattern

  • ClaimRequestObserver: Monitors field changes
  • Auto-Status Updates: Based on claim_number, approval amounts
  • Closure Detection: LOB-specific closure logic
  • Audit Logging: Comprehensive change tracking
