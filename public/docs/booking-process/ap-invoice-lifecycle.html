🏭 AP Invoice Lifecycle

Comprehensive guide to Accounts Payable invoice creation, management and posting in Sage 300

🎯 Overview

The AP Invoice lifecycle manages the complete process of creating, processing, and posting Accounts Payable invoices in Sage 300 ERP system for vendor payments to insurance providers. This includes Premium invoices for insurer payments that follow the standard Sage workflow: Open → Ready to Post → Posted.

💡 Core AP Invoice Operations

Premium Invoices for insurance provider payments, Split Payment Invoices for installment-based policies, Vendor payment processing for insurance premiums, and systematic status management through Sage 300 invoice batch processing with comprehensive error handling and recovery mechanisms.

🔧 Function Types in This Documentation

  • Sage API Service Methods: Handle actual API calls to Sage 300
  • Payload Factory Methods: Generate API request structures
  • Location: SageApiService.php & SagePayloadFactory.php

🗄️ Database Storage

  • Vendor References: Insurance provider Sage vendor IDs
  • Invoice Numbers: Document numbers for AP invoices
  • Process Logs: sage_api_logs table for all operations

Installment-based premium invoices for split payment schedules. Each installment creates corresponding vendor payment obligations.

Invoice Status Lifecycle

All AP invoices follow: Create (Open) → Mark Ready to Post → Post to General Ledger (Posted) → Complete

2

📦 AP Invoice Creation Scenarios

AP invoices are created for vendor payments to insurance providers across three main scenarios:

🏠 Main Lead Policy Booking

  • Context: Standard policy booking requiring insurer payment
  • Invoice Types: Premium Invoice to vendor (insurance provider)
  • Payment Modes: Upfront or Split Payment with schedules
  • GL Account: Uses insurerGlLiaiblityAccount from insurer config

🔗 Embedded Product Booking

  • Context: EP vendor payment to embedded product provider
  • Invoice Types: EP Premium Invoice
  • Special Handling: Separate from main policy AP invoice
  • Revenue Account: EP-specific vendor payment account

📝 Send Update (Endorsements)

  • Context: Policy changes requiring vendor payment adjustment
  • Invoice Types: Straight (additional) or Reversal + Correction
  • Entry Types: SCT_STRAIGHT, SCT_REVERSAL
  • Purpose: Adjust vendor payment obligations for changes

⚡ Key Differences: AP vs AR Invoices

AP Invoices: Payments TO vendors (insurance providers) - represents company's obligations
AR Invoices: Payments FROM customers - represents company's receivables
Vendor ID: AP uses sageVenderId from insurance_providers table
Customer ID: AR uses customerId from customers/entities tables

💰 Upfront Payment AP Invoice Creation

Payment Frequency: PaymentFrequency::UPFRONT | Context: Single vendor payment to insurance provider

📋 Characteristics

💳 Payment Structure

  • Single payment to vendor (insurance provider)
  • Immediate vendor payment obligation
  • No payment schedules for vendor
  • Full premium amount to insurer

📄 Invoice Structure

  • Single AP invoice to vendor
  • Uses insurerGlLiaiblityAccount GL account
  • Terms Code: 'COD' for upfront payment
  • No PaymentSchedules array needed

🗄️ Vendor Details

  • Vendor ID from insurance_providers.sageVenderId
  • GL Account from insurance_providers.insurerGlLiaiblityAccount
  • Direction: Payment TO vendor (not FROM)
  • Represents company's payment obligation

🔄 Workflow Steps

  • Step 1: Create AP Invoice (OPEN status)
  • Step 2: Ready to Post (PATCH to READY_TO_POST)
  • Step 3: Post to GL (POST to POSTED status)
  • Creates vendor payment obligation in Sage

🔧 Implementation: createUpfrontAPInvoicePrem()

Service: SageApiService.php | Method: createUpfrontAPInvoicePrem()

private function createUpfrontAPInvoicePrem($sageRequestDataArray)
{
    [$sageRequest, $quote, $payment, $paymentSplits, $sageLogArray, $extraDetails] = $sageRequestDataArray;
    $totalSteps = 15;
    $currentStep = 10;

    $sageEntryType = $extraDetails['sage_entry_type'] ?? SageEnum::SCT_STRAIGHT;
    $reverseInvoiceDetails = $extraDetails['sageReversalInvoice'] ?? '';

    // Step 1: Create AP Invoice to vendor
    $payLoadOptions = SagePayloadFactory::createAPInvoicePrem(
        request: $sageRequest,
        type: $sageEntryType,
        reversalDetails: $reverseInvoiceDetails,
        extras: $extraDetails
    );

    $resp = $this->postToSage300($payLoadOptions['endPoint'], $payLoadOptions['payload']);
    $sageResponse = json_decode($resp, true);

    if (!empty($sageResponse['BatchNumber'])) {
        $this->logSageApiCall($payLoadOptions, $sageResponse, $quote, $quote, $currentStep, $totalSteps, SageEnum::STATUS_SUCCESS);

        // Step 2: Ready to Post
        $currentStep = 11;
        $readyToPostInvoiceAp = SagePayloadFactory::readyToPostInvoiceAp($sageResponse['BatchNumber'], $sageEntryType);
        $readyResp = $this->postToSage300($readyToPostInvoiceAp['endPoint'], $readyToPostInvoiceAp['payload'], 'PATCH');

        $this->logSageApiCall($readyToPostInvoiceAp, json_decode($readyResp, true), $quote, $quote, $currentStep, $totalSteps, SageEnum::STATUS_SUCCESS);

        // Step 3: Post to General Ledger
        $currentStep = 12;
        $apPostInvoices = SagePayloadFactory::aPPostInvoices($sageResponse['BatchNumber'], $sageEntryType);
        $postResp = $this->postToSage300($apPostInvoices['endPoint'], $apPostInvoices['payload']);

        $this->logSageApiCall($apPostInvoices, json_decode($postResp, true), $quote, $quote, $currentStep, $totalSteps, SageEnum::STATUS_SUCCESS);

        return ['status' => true, 'message' => 'Upfront AP invoice created and posted'];
    }

    return ['status' => false, 'message' => 'AP invoice creation failed'];
}

💡 Key Points for Upfront AP Invoices

Vendor Payment: AP invoices represent payments TO vendors (insurance providers)
GL Account: Uses insurerGlLiaiblityAccount from insurance provider configuration
Single Transaction: Full premium amount in one invoice to vendor
Immediate Obligation: Creates immediate payment obligation in Sage 300

📅 Split Payment AP Invoice Creation

Payment Frequency: PaymentFrequency::SPLIT_PAYMENTS | Context: Installment-based vendor payments

📋 Characteristics

💳 Payment Structure

  • Multiple vendor payment obligations
  • Aligned with customer installments
  • Future payments scheduled in PaymentSchedules
  • Each vendor payment matches customer split

📄 Invoice Structure

  • AP invoice with PaymentSchedules array
  • Future vendor payment obligations
  • Terms Code: SPLIT2-SPLIT9, SPLI10+
  • Partial vendor payments tracked

🔄 Vendor Payment Tracking

  • Each installment creates vendor obligation
  • Payment due dates match customer splits
  • Vendor gets paid as customer pays
  • Future obligations in PaymentSchedules

⚖️ Balance Maintenance

  • Customer AR vs Vendor AP balance
  • Split payment synchronization
  • Installment amount matching
  • Due date alignment

private function createNonUpfrontAPInvoicePrem($sageRequestDataArray)
{
    [$sageRequest, $quote, $payment, $paymentSplits, $sageLogArray, $extraDetails] = $sageRequestDataArray;
    $totalSteps = 15;
    $currentStep = 10;

    $sageEntryType = $extraDetails['sage_entry_type'] ?? SageEnum::SCT_STRAIGHT;
    $reverseInvoiceDetails = $extraDetails['sageReversalInvoice'] ?? '';

    // Separate paid and unpaid splits for vendor payment obligations
    $paidSplits = $paymentSplits->whereIn('payment_status_id', [
        PaymentStatusEnum::PAID,
        PaymentStatusEnum::CAPTURED
    ]);

    $unpaidSplits = $paymentSplits->whereNotIn('payment_status_id', [
        PaymentStatusEnum::PAID,
        PaymentStatusEnum::CAPTURED
    ]);

    LoggerService::info('Split Payment AP Invoice: Vendor Obligations - Paid='.$paidSplits->count().' Future='.$unpaidSplits->count());

    // Create AP invoice with payment schedules for future vendor obligations
    $payLoadOptions = SagePayloadFactory::createAPInvoiceSplitPayments(
        $sageRequest,
        $paymentSplits,  // All splits for vendor payment schedules
        $sageEntryType,
        $reverseInvoiceDetails,
        $extraDetails
    );

    $resp = $this->postToSage300($payLoadOptions['endPoint'], $payLoadOptions['payload']);
    $sageResponse = json_decode($resp, true);

    if (!empty($sageResponse['BatchNumber'])) {
        $this->logSageApiCall($payLoadOptions, $sageResponse, $quote, $quote, $currentStep, $totalSteps, SageEnum::STATUS_SUCCESS);

        // Ready to Post
        $currentStep = 11;
        $readyToPostInvoiceAp = SagePayloadFactory::readyToPostInvoiceAp($sageResponse['BatchNumber'], $sageEntryType);
        $readyResp = $this->postToSage300($readyToPostInvoiceAp['endPoint'], $readyToPostInvoiceAp['payload'], 'PATCH');

        $this->logSageApiCall($readyToPostInvoiceAp, json_decode($readyResp, true), $quote, $quote, $currentStep, $totalSteps, SageEnum::STATUS_SUCCESS);

        // Post to GL
        $currentStep = 12;
        $apPostInvoices = SagePayloadFactory::aPPostInvoices($sageResponse['BatchNumber'], $sageEntryType);
        $postResp = $this->postToSage300($apPostInvoices['endPoint'], $apPostInvoices['payload']);

        $this->logSageApiCall($apPostInvoices, json_decode($postResp, true), $quote, $quote, $currentStep, $totalSteps, SageEnum::STATUS_SUCCESS);

        return ['status' => true, 'message' => 'Split payment AP invoice created'];
    }

    return ['status' => false, 'message' => 'AP split payment invoice creation failed'];
}

🛠️ Core AP Invoice Creation Functions

📍 Function Type: These are Sage API Service Methods that orchestrate AP invoice creation processes.

🏭 createAPInvoicePrem() - API Service Method

Main orchestrator function in SageApiService that creates AP Premium invoices based on payment frequency.

private function createAPInvoicePrem($sageRequestDataArray)
{
    $sageRequestDataArray = array_pad($sageRequestDataArray, 6, []);
    [$sageRequest, $quote, $payment, $paymentSplits, $sageLogArray, $extraDetails] = $sageRequestDataArray;

    $isPaymentFrequencyUpfront = $extraDetails['reversalFrequency'] ?? ($payment->frequency == PaymentFrequency::UPFRONT);

    if ($isPaymentFrequencyUpfront) {
        return $this->createUpfrontAPInvoicePrem([$sageRequest, $quote, $payment, $paymentSplits, $sageLogArray, $extraDetails]);
    } else {
        return $this->createNonUpfrontAPInvoicePrem([$sageRequest, $quote, $payment, $paymentSplits, $sageLogArray, $extraDetails]);
    }
}

🔧 Individual AP Invoice Creation Methods

📍 Function Type: These are Sage API Service Methods that handle specific AP invoice types.

🏭 createUpfrontAPInvoicePrem() - API Service Method (3 Steps)

Creates upfront AP premium invoices in SageApiService through complete Open → Ready to Post → Posted lifecycle.

1

Create Invoice (OPEN)

Create AP invoice batch with createAPInvoicePrem()

2

Ready to Post

Mark batch ready for posting with readyToPostInvoiceAp()

3

Post to GL (POSTED)

Post invoice to general ledger with apPostInvoices()

private function createUpfrontAPInvoicePrem($sageRequestDataArray)
{
    [$sageRequest, $quote, $payment, $paymentSplits, $sageLogArray, $extraDetails] = $sageRequestDataArray;
    $returnMessage = ['status' => false, 'message' => null, 'error' => null];

    $sageEntryType = $extraDetails['sage_entry_type'] ?? SageEnum::SCT_STRAIGHT;
    $reverseInvoiceDetails = $extraDetails['sageReversalInvoice'] ?? '';

    // Step 1: Create AP Invoice (OPEN Status)
    $payLoadOptions = SagePayloadFactory::createAPInvoicePrem(
        request: $sageRequest,
        type: $sageEntryType,
        reversalDetails: $reverseInvoiceDetails,
        extras: $extraDetails
    );
    $resp = $this->postToSage300($payLoadOptions['endPoint'], $payLoadOptions['payload']);
    $sageResponse = json_decode($resp, true);

    if (!empty($sageResponse['BatchNumber'])) {
        // Step 2: Ready to Post (OPEN → READY TO POST)
        $readyToPostInvoiceAp = SagePayloadFactory::readyToPostInvoiceAp(
            batchNumber: $sageResponse['BatchNumber'],
            type: $sageEntryType,
            extras: $extraDetails
        );
        $readyToPostResponse = $this->postToSage300($readyToPostInvoiceAp['endPoint'], $readyToPostInvoiceAp['payload'], 'PATCH');

        // Step 3: Post to General Ledger (READY TO POST → POSTED)
        $apPostInvoices = SagePayloadFactory::apPostInvoices(
            batchNumber: $sageResponse['BatchNumber'],
            type: $sageEntryType,
            extras: $extraDetails
        );
        $postedResponse = $this->postToSage300($apPostInvoices['endPoint'], $apPostInvoices['payload']);

        return ['status' => true, 'message' => 'AP Premium invoice created'];
    }

    return ['status' => false, 'message' => 'Batch number not generated from sage'];
}

📊 createNonUpfrontAPInvoicePrem() - API Service Method

Creates split payment AP invoices in SageApiService for installment-based premium payments to insurance providers.

private function createNonUpfrontAPInvoicePrem($sageRequestDataArray)
{
    [$sageRequest, $quote, $payment, $paymentSplits, $sageLogArray, $extraDetails] = $sageRequestDataArray;

    // Create split payment AP invoice for vendor payments
    $payLoadOptions = SagePayloadFactory::createAPInvoicePrem(
        request: $sageRequest,
        type: $sageEntryType,
        reversalDetails: $reverseInvoiceDetails,
        extras: $extraDetails
    );
    $resp = $this->postToSage300($payLoadOptions['endPoint'], $payLoadOptions['payload']);
    $sageResponse = json_decode($resp, true);

    if (!empty($sageResponse['BatchNumber'])) {
        // Follow same Ready to Post → Posted lifecycle
        $readyToPostInvoiceAp = SagePayloadFactory::readyToPostInvoiceAp($sageResponse['BatchNumber'], $sageEntryType, $extraDetails);
        $readyToPostResponse = $this->postToSage300($readyToPostInvoiceAp['endPoint'], $readyToPostInvoiceAp['payload'], 'PATCH');

        $apPostInvoices = SagePayloadFactory::apPostInvoices($sageResponse['BatchNumber'], $sageEntryType, $extraDetails);
        $postedResponse = $this->postToSage300($apPostInvoices['endPoint'], $apPostInvoices['payload']);

        return ['status' => true, 'message' => 'AP Split Payment invoice created'];
    }

    return ['status' => false, 'message' => 'AP invoice creation failed'];
}

🏭 Payload Factory Methods

📍 Function Type: These are Payload Factory Methods that generate Sage 300 API request structures.

🏭 createAPInvoicePrem() - Payload Factory Method

Static method in SagePayloadFactory that creates the Sage 300 AP premium invoice payload structure for vendor payments.

public static function createAPInvoicePrem($request, $type = SageEnum::SCT_STRAIGHT, $reversalDetails = '', $extras = [])
{
    $optionalFields = self::createOptionalFields($request);
    // Additional Option Field just for AP Invoice
    $optionalFields[] = [
        'OptionalField' => 'IGTC',
        'Value' => 'N',
    ];

    $premiumDescription = 'P.'.$request->invoiceDescription;
    $invoicePaymentSchedulesDueDate = self::calculateDueDate($request->paymentDueDate, $request->insurerInvoiceDate);

    $payLoad = [
        'Invoices' => [
            [
                'VendorNumber' => $request->sageVenderId,  // Insurance provider vendor number
                'DocumentNumber' => $request->insurerPremiumNumber,
                'InvoiceDescription' => $premiumDescription,
                'DocumentDate' => Carbon::parse($request->insurerInvoiceDate)->format(self::instanceData()->sage_api_date_format),
                'CurrencyCode' => 'AED',
                'DueDate' => $invoicePaymentSchedulesDueDate,
                'AsOfDate' => $invoicePaymentSchedulesDueDate,
                'TaxGroup' => 'VAT',
                'TaxClass1' => 5,
                'TaxAmount1' => 0.000,
                'DocumentTotalBeforeTaxes' => roundNumber($request->premiumWithTax),
                'DocumentTotalIncludingTax' => roundNumber($request->premiumWithTax),
                'InvoiceDetails' => [
                    [
                        'Description' => $premiumDescription,
                        'TaxClass1' => 5,
                        'ExpenseAccount' => '50010',  // AP expense account
                        'ExtendedAmountWithTIP' => roundNumber($request->premiumWithTax),
                        'ExtendedAmountWithoutTIP' => roundNumber($request->premiumWithTax),
                    ],
                ],
                'InvoiceOptionalField' => $optionalFields,
            ],
        ],
    ];

    return [
        'endPoint' => 'AP/APInvoiceBatches',
        'payload' => $payLoad,
        'sage_request_type' => SageEnum::SRT_CREATE_AP_PREM_INV,
        'entry_type' => $type,
    ];
}
