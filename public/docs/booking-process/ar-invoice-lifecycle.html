📄 AR Invoice Lifecycle

Comprehensive guide to Accounts Receivable invoice creation, posting, and management in Sage 300

🎯 Overview

The AR Invoice Lifecycle manages the complete process of creating, posting, and tracking Accounts Receivable invoices in Sage 300 ERP system. This includes Premium invoices, Commission invoices, and Discount credit notes with their complete lifecycle: Create (Open) → Ready to Post → Posted to General Ledger.

💡 Core AR Invoice Operations

Premium Invoices for insurance policy premiums, Commission Invoices for broker/agent commissions, Discount Credit Notes for customer discounts, and systematic status management through Sage 300 batch processing workflow with comprehensive error handling and audit logging.

🔧 Function Types in This Documentation

  • Sage API Service Methods: Handle actual API calls to Sage 300
  • Payload Factory Methods: Generate API request structures
  • Location: SageApiService.php & SagePayloadFactory.php

🗄️ Database Storage

  • Premium Invoice Numbers: payments.tax_invoice_number
  • Commission Invoice Numbers: payments.insurer_commmission_invoice_number
  • Purpose: Track and reference Sage invoice batches

📋 AR Invoice Types

💰

Premium Invoice

Customer premium invoices for insurance policies. Created with DocumentType 'Invoice' and goes through Open → Ready to Post → Posted status cycle.

💼

Commission Invoice

Broker/agent commission invoices created against insurance providers. Follows same status workflow with proper VAT handling.

🏷️

Discount Credit Note

Credit notes for customer discounts. Created with DocumentType 'CreditNote' to reduce customer outstanding balance.

🔄

Invoice Status Lifecycle

All invoices follow: Create (Open) → Mark Ready to Post → Post to General Ledger (Posted) → Complete

🔄 Invoice Status Lifecycle Workflow

1

Create Invoice (Open)

Generate AR invoice batch in Sage 300 with initial "Open" status

2

Ready to Post

Mark invoice batch as "Ready to Post" status for validation and preparation

3

Post to General Ledger

Post invoice batch to GL, changing status from "Ready to Post" to "Posted"

🛠️ Core Invoice Creation Functions

📍 Function Type: These are Sage API Service Methods that orchestrate invoice creation and posting.

💰 createARInvoicePremAndComm() - API Service Method

Main function in SageApiService for creating AR premium and commission invoices with complete lifecycle management.

private function createARInvoicePremAndComm($sageRequestDataArray)
{
    [$sageRequest, $quote, $payment, $paymentSplits, $sageLogArray, $extraDetails] = $sageRequestDataArray;
    $sageEntryType = $extraDetails['sage_entry_type'] ?? SageEnum::SCT_STRAIGHT;
    $reverseInvoiceDetails = $extraDetails['sageReversalInvoice'] ?? '';
    $userId = $extraDetails['userId'] ?? null;

    // Step 1: Create AR Invoice (OPEN Status)
    $payLoadOptions = SagePayloadFactory::createARInvoicePremAndComm(
        request: $sageRequest,
        type: $sageEntryType,
        reversalDetails: $reverseInvoiceDetails,
        extras: $extraDetails
    );

    $resp = $this->postToSage300($payLoadOptions['endPoint'], $payLoadOptions['payload']);
    $sageResponse = json_decode($resp, true);

    if (!empty($sageResponse['BatchNumber'])) {
        LoggerService::info('SAGE API : '.$quote->code.' : Batch Number - '.$sageResponse['BatchNumber'].' for createARInvoicePremAndComm');

        // Step 2: Ready to Post (OPEN → READY TO POST)
        $readyToPostInvoiceAr = SagePayloadFactory::readyToPostInvoiceArPayment($sageResponse['BatchNumber']);
        $readyToPostResponse = $this->postToSage300($readyToPostInvoiceAr['endPoint'], $readyToPostInvoiceAr['payload'], 'PATCH');

        // Step 3: Post to General Ledger (READY TO POST → POSTED)
        $aRPostInvoices = SagePayloadFactory::aRPostInvoicesPayment($sageResponse['BatchNumber']);
        $postedResponse = $this->postToSage300($aRPostInvoices['endPoint'], $aRPostInvoices['payload']);

        return ['status' => true, 'message' => 'AR Premium and Commission invoice created on sage'];
    }

    return ['status' => false, 'message' => 'Batch number not generated from sage'];
}

🏷️ createARInvoiceDis() - API Service Method

Function in SageApiService for creating AR discount credit notes with complete status lifecycle.

public function createARInvoiceDis($sageRequestDataArray)
{
    [$sageRequest, $quote, $sageLogArray, $extraDetails] = $sageRequestDataArray;
    $sageEntryType = $extraDetails['sage_entry_type'] ?? SageEnum::SCT_STRAIGHT;
    $reverseInvoiceDetails = $extraDetails['sageReversalInvoice'] ?? '';
    $userId = $extraDetails['userId'] ?? null;

    if ($sageRequest->discount > 0) {
        // Step 1: Create AR Discount Credit Note (OPEN Status)
        $createARInvoiceDis = SagePayloadFactory::createARInvoiceDis(
            request: $sageRequest,
            type: $sageEntryType,
            reversalDetails: $reverseInvoiceDetails,
            extras: $extraDetails
        );

        $resp = $this->postToSage300($createARInvoiceDis['endPoint'], $createARInvoiceDis['payload']);
        $postedResponse = json_decode($resp, true);

        if (!empty($postedResponse['BatchNumber'])) {
            LoggerService::info('SAGE API : '.$quote->code.' : createARInvoiceDis - BatchNumber : '.$postedResponse['BatchNumber'].' completed successfully');

            // Step 2: Ready to Post (OPEN → READY TO POST)
            $readyToPostInvoiceAr = SagePayloadFactory::readyToPostInvoiceArPayment($postedResponse['BatchNumber']);
            $readyToPostResponse = $this->postToSage300($readyToPostInvoiceAr['endPoint'], $readyToPostInvoiceAr['payload'], 'PATCH');

            // Step 3: Post to General Ledger (READY TO POST → POSTED)
            $aRPostInvoices = SagePayloadFactory::aRPostInvoicesPayment($postedResponse['BatchNumber']);
            $finalPostedResponse = $this->postToSage300($aRPostInvoices['endPoint'], $aRPostInvoices['payload']);

            return ['status' => true, 'message' => 'AR Discount invoice created on sage'];
        }

        return ['status' => false, 'message' => 'createARInvoiceDis failed'];
    }

    return ['status' => true, 'message' => 'No discount to process'];
}

💰 createARInvoicePremAndComm() - Payload Factory Method

public static function createARInvoicePremAndComm($request, $type = SageEnum::SCT_STRAIGHT, $reversalDetails = '', $extras = [])
{
    // Tax class determination for commission VAT
    $taxClass = 2;
    if ($request->commissionIncludingVat > 0) {
        $taxClass = 1;
    }

    $premiumDescription = 'P.'.$request->invoiceDescription;
    $commissionDescription = 'C.'.$request->invoiceDescription;
    $invoicePaymentSchedulesDueDate = self::calculateDueDate($request->paymentDueDate, $request->insurerInvoiceDate);
    $optionalFields = self::createOptionalFields($request, SageEnum::SRT_CREATE_AR_PREM_COMM_INV);

    $payLoad = [
        'Invoices' => [
            [
                // Premium Invoice
                'CustomerNumber' => $request->customerId,
                'DocumentNumber' => $request->insurerPremiumNumber,
                'InvoiceDescription' => $premiumDescription,
                'DocumentDate' => Carbon::parse($request->insurerInvoiceDate)->format(self::instanceData()->sage_api_date_format),
                'CurrencyCode' => 'AED',
                'DueDate' => $invoicePaymentSchedulesDueDate,
                'AsOfDate' => $invoicePaymentSchedulesDueDate,
                'TaxGroup' => 'VAT',
                'TaxClass1' => 5,
                'TaxAmount1' => 0.000,
                'DocumentTotalBeforeTax' => roundNumber($request->premiumWithTax),
                'DocumentTotalIncludingTax' => roundNumber($request->premiumWithTax),
                'InvoiceDetails' => [
                    [
                        'Description' => $premiumDescription,
                        'TaxClass1' => 5,
                        'RevenueAccount' => $request->insurerGlLiaiblityAccount,
                        'ExtendedAmountWithTIP' => roundNumber($request->premiumWithTax),
                        'ExtendedAmountWithoutTIP' => roundNumber($request->premiumWithTax),
                    ],
                ],
                'InvoicePaymentSchedules' => [
                    [
                        'DueDate' => $invoicePaymentSchedulesDueDate,
                    ],
                ],
                'InvoiceOptionalFields' => $optionalFields,
            ],
            [
                // Commission Invoice
                'CustomerNumber' => $request->sageInsurerCustomerId,
                'DocumentNumber' => $request->insurerCommissionNumber,
                'InvoiceDescription' => $commissionDescription,
                'DocumentDate' => Carbon::parse($request->insurerInvoiceDate)->format(self::instanceData()->sage_api_date_format),
                'CurrencyCode' => 'AED',
                'DueDate' => $invoicePaymentSchedulesDueDate,
                'AsOfDate' => $invoicePaymentSchedulesDueDate,
                'TaxGroup' => 'VAT',
                'TaxClass1' => $taxClass,
                'TaxAmount1' => roundNumber($request->vatOnCommission),
                'DocumentTotalBeforeTax' => $request->commissionIncludingVat > 0 ? roundNumber($request->commissionIncludingVat) : roundNumber($request->commissionWithOutVat),
                'DocumentTotalIncludingTax' => $request->commissionIncludingVat > 0 ? roundNumber($request->commissionIncludingVat) : roundNumber($request->commissionWithOutVat),
                'InvoiceDetails' => [
                    [
                        'Description' => $commissionDescription,
                        'TaxClass1' => $taxClass,
                        'TaxAmount1' => roundNumber($request->vatOnCommission),
                        'RevenueAccount' => '60010',
                        'ExtendedAmountWithTIP' => roundNumber($request->commissionIncludingVat > 0 ? $request->commissionIncludingVat : $request->commissionWithOutVat),
                        'ExtendedAmountWithoutTIP' => roundNumber($request->commissionIncludingVat > 0 ? $request->commissionIncludingVat : $request->commissionWithOutVat),
                    ],
                ],
                'InvoicePaymentSchedules' => [
                    [
                        'DueDate' => $invoicePaymentSchedulesDueDate,
                    ],
                ],
                'InvoiceOptionalFields' => $optionalFields,
            ],
        ],
    ];

    return [
        'endPoint' => 'AR/ARInvoiceBatches',
        'payload' => $payLoad,
        'sage_request_type' => SageEnum::SRT_CREATE_AR_PREM_COMM_INV,
        'entry_type' => SageEnum::SCT_STRAIGHT,
    ];
}

🔧 Invoice Processing Logic

📋 Payment Frequency Based Processing

AR invoice creation varies based on payment frequency, determining whether to create upfront invoices or split payment invoices with individual installment tracking.

💳 Upfront Payment Invoicing

  • Frequency: PaymentFrequency::UPFRONT
  • Method: createUpfrontARInvoicePremAndComm()
  • Invoices: Single premium + commission invoice
  • Processing: Complete payment in one transaction

📅 Split Payment Invoicing

  • Frequency: PaymentFrequency::SPLIT_PAYMENTS
  • Method: createARInvoiceSplitPayments()
  • Invoices: Multiple invoices per payment split
  • Processing: Individual installment tracking
// Payment frequency determination logic
if ($payment->frequency == PaymentFrequency::UPFRONT) {
    // Create single upfront invoice
    $createARInvoicePremAndComm = $this->createUpfrontARInvoicePremAndComm(
        [$sageRequest, $quote, $payment, $paymentSplits, $sageLogArray, $extraDetails]
    );
} else {
    // Create split payment invoices
    $createARInvoiceSplitPayments = SagePayloadFactory::createARInvoiceSplitPayments(
        $sageRequest,
        $paymentSplits,
        $sageEntryType,
        $reverseInvoiceDetails,
        $extraDetails
    );
}

🏷️ Discount Processing Logic

Discount credit notes are created only when discount amount is greater than zero.

// Discount credit note creation logic
if ($sageRequest->discount > 0 && !in_array($sendUpdateLogStatus, [
    SendUpdateLogStatusEnum::ATIB,
    SendUpdateLogStatusEnum::ACB,
    SendUpdateLogStatusEnum::ATCRNB,
    SendUpdateLogStatusEnum::ATCRNB_RBB,
])) {
    $createARInvoiceDis = $this->createARInvoiceDis([
        $sageRequest,
        $quote,
        $sageLogArray,
        $extraDetails
    ]);

    if (!$createARInvoiceDis['status']) {
        return $createARInvoiceDis;
    }
}

💰 createARInvoicePremAndComm() Status Flow

The actual AR invoice creation function follows the Open → Ready to Post → Posted lifecycle using existing methods.

// Step 1: Create AR Invoice (OPEN Status)

}

🔍 Error Recovery in Actual Functions

🚨 AR Invoice Error Handling

  • Batch Status Check: GET AR/ARInvoiceBatches
  • Already Posted Check: BatchStatus == 'POSTED'
  • Batch Number Validation: Check BatchNumber exists
  • Step Tracking: Individual step success/failure logging

🚨 Discount Invoice Error Handling

  • Amount Validation: discount > 0 check
  • Status Exclusion: Skip for certain update statuses
  • Batch Processing: Same lifecycle as regular invoices
  • Credit Note Validation: DocumentType verification
