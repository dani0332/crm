🔍 Pre-Booking Validation Checks (postBookPolicyToSage)

Critical validation checks performed inside the postBookPolicyToSage function before initiating the actual Sage booking process.

🚦 Core System Checks

Policy Already Booked quote_status_id == QuoteStatusEnum::PolicyBooked
Sage System Status isSageEnabled() must return true
Embedded Product Status isEmbeddedTransactionStatusReadyForSage() check
Quote Type Resolution QuoteTypes::getIdFromValue() validation

💳 Payment Validation Logic

Payment Record Lookup Payment::where('code', $quote->code)->mainLeadPayment()
Duplicate Lead Handling Check parent_duplicate_quote_id for payment resolution
Credit Card Payment Check Unpaid CC payments with INSURER collection type
Zero Price Validation total_price == 0 requires CreditApproval payment method

🏢 Health AUH Lead Processing

AUH Lead Detection isAHisHealthAUHLead() check for special processing
Document Send Check isPolicySentLogExists() for customer documents
Status Update Direct PolicyBooked status for AUH leads
Payment Processing straightforwardPayments() for AUH leads

🔑 Required Sage IDs (checkRequiredSageIds)

Customer Sage ID sageRequest->customerId must exist
GL Account sageRequest->insurerGlLiaiblityAccount required
Sage Vendor ID sageRequest->sageVenderId for insurance provider
Insurer Customer ID sageRequest->sageInsurerCustomerId required

⚙️ Payment Method & Frequency Validation

Zero Price Policy Only allowed with CreditApproval + UPFRONT frequency
Payment Status Check isPaymentPaidOrCreditApproved() validation
Commission Charges Extract commission charge IDs from payment splits
Customer Verification verifySageCustomer() with 13 total steps
