🧾 Receipt Creation Process

Comprehensive guide to payment receipt generation and invoice mapping in Sage 300

🎯 Overview

The receipt creation process specifically handles the generation and posting of payment receipts and prepayments in Sage 300 ERP system for both Accounts Receivable (AR) and Accounts Payable (AP). This process manages the complete lifecycle of receipts from creation through status transitions: Open → Ready to Post → Posted.

💡 Core Receipt Operations

AR Prepayment Receipts for customer advance payments, AP Payment Receipts for vendor payments, Commission Receipts for broker/agent payments, and systematic status management through Sage 300 batch processing workflow with comprehensive error handling and recovery mechanisms.

🔧 Function Types in This Documentation

  • Sage API Service Methods: Handle actual API calls to Sage 300
  • Payload Factory Methods: Generate API request structures
  • Location: SageApiService.php & SagePayloadFactory.php

🗄️ Database Storage

  • AR Receipt IDs: payment_splits.sage_reciept_id
  • AP Payment IDs: payment_splits.sage_ap_payment_receipt_id
  • Purpose: Track and reference Sage receipt batches

📋 AR & AP Receipt Types

💳

AR Prepayment Receipts

Customer advance payment receipts created in AR module. Goes through Open → Ready to Post → Posted status cycle.

🏦

AP Payment Receipts

Vendor payment receipts created in AP module for insurance provider payments. Follows same status workflow.

💼

Commission Receipts

Broker/agent commission payment receipts. Can be both AR (receiving commission) or AP (paying commission) depending on flow.

🔄

Receipt Status Lifecycle

All receipts follow: Create (Open) → Mark Ready to Post → Post to General Ledger (Posted) → Complete

🛠️ Core Receipt Creation Functions

📍 Function Type: These are Sage API Service Methods that orchestrate multiple receipt creation calls.

💳 createARPrepaymentPremiumReceipts() - API Service Method

Main orchestrator function in SageApiService for creating AR prepayment receipts for multiple paid payment splits.

private function createARPrepaymentPremiumReceipts($sageRequestDataArray, $splitAmount = null)
{
    [$sageRequest, $quote, $payment, $paymentSplits] = $sageRequestDataArray;
    $prepaymentResponses = [];
    
    // Get all paid payment splits (PAID, PARTIALLY_PAID, CAPTURED)
    $paidPaymentSplits = $payment->paymentSplits()
        ->whereIn('payment_status_id', [PaymentStatusEnum::PAID, PaymentStatusEnum::PARTIALLY_PAID, PaymentStatusEnum::CAPTURED])
        ->get();

    foreach ($paidPaymentSplits as $paymentSplit) {
        // Skip credit approval payments
        $isPaymentMethodCA = in_array($paymentSplit->payment_method, [PaymentMethodsEnum::CreditApproval]);
        if ($isPaymentMethodCA) {
            LoggerService::info('Posting of prepayment skipped due to credit approval');
            $prepaymentResponses[] = ['status' => true, 'message' => 'Skipped due to credit approval'];
            continue;
        }
        
        // Create individual AR prepayment receipt
        $createPrepaymentReceiptResponse = $this->createARPrepaymentPremiumReceipt($sageRequest, $quote, $payment, $paymentSplit);
        $prepaymentResponses[] = $createPrepaymentReceiptResponse;
    }

    // Check for any failures
    foreach ($prepaymentResponses as $item) {
        if ($item['status'] === false) {
            return ['status' => false, 'message' => $item['message']];
        }
    }

    return ['status' => true, 'message' => 'AR Prepayment Receipts posted on sage.'];
}

🔧 Individual Receipt Creation Methods

📍 Function Type: These are Sage API Service Methods that handle individual receipt creation with API calls.

💳 createARPrepaymentPremiumReceipt() - API Service Method (4 Steps)

Creates individual AR prepayment receipt in SageApiService through complete Open → Ready to Post → Posted lifecycle.

1

Customer Verification

Get Sage customer number using getSageCustomerNumber()

2

Create Receipt (OPEN)

Create AR prepayment receipt batch with createPrepaymentReceiptPayload()

3

Ready to Post

Mark batch ready for posting with readyToPostReceiptArPayment()

4

Post to GL (POSTED)

Post receipt to general ledger with aRPostReceiptsPayment()

public function createARPrepaymentPremiumReceipt($sageRequest, $quote, $payment, $paymentSplit, $splitAmount = null)
{
    // Step 1: Prepare data and get customer number
    $sageRequest = SagePayloadFactory::globalSagePrepaymentReceiptPayloadData([$quote, $payment, $paymentSplit, $sageRequest, $splitAmount]);
    $sageCustomerNumberResponse = $sageApiService->getSageCustomerNumber(...);
    $sageRequest->sage_customer_number = $sageCustomerNumberResponse['sageCustomerNumber'];
    
    // Step 2: Create AR Prepayment Receipt (OPEN Status)
    $payLoadOptions = SagePayloadFactory::createPrepaymentReceiptPayload($sageRequest);
    $createPremiumPrepaymentResponse = $sageApiService->postToSage300($payLoadOptions['endPoint'], $payLoadOptions['payload']);
    $sageResponse = json_decode($createPremiumPrepaymentResponse, true);
    
    if (isset($sageResponse['ReceiptsAdjustments'][0]['DocumentNumber'])) {
        // Update payment split with receipt ID
        $documentNumberForReceipt = $sageResponse['ReceiptsAdjustments'][0]['DocumentNumber'];
        $paymentSplit->update(['sage_reciept_id' => $documentNumberForReceipt]);
        
        // Step 3: Ready to Post (OPEN → READY TO POST)
        $readyToPostReceiptAr = SagePayloadFactory::readyToPostReceiptArPayment($sageResponse['BatchNumber']);
        $readyToPostResponse = $sageApiService->postToSage300($readyToPostReceiptAr['endPoint'], $readyToPostReceiptAr['payload'], 'PATCH');
        
        // Step 4: Post to General Ledger (READY TO POST → POSTED)
        $aRPostReceipts = SagePayloadFactory::aRPostReceiptsPayment($sageResponse['BatchNumber']);
        $postedResponse = $sageApiService->postToSage300($aRPostReceipts['endPoint'], $aRPostReceipts['payload']);
        
        return ['status' => true, 'message' => 'Prepayment created'];
    }
    
    return ['status' => false, 'message' => 'Document number not generated from sage'];
}

🏦 createAPPrepaymentPremiumReceipt() - API Service Method (3 Steps)

Creates individual AP prepayment receipt in SageApiService for vendor payments through complete lifecycle.

5

Create AP Payment (OPEN)

Create AP prepayment payment batch with createAPPrepaymentReceiptPayload()

6

Ready to Post

Mark batch ready for posting with readyToPostAPPaymentReceiptPayload()

7

Post to GL (POSTED)

Post payment to general ledger with postAPPaymentReceiptPayload()

public function createAPPrepaymentPremiumReceipt($sageRequest, $quote, $payment, $paymentSplit, $splitAmount = null)
{
    // Step 5: Create AP Prepayment Payment (OPEN Status)
    $sageRequest = SagePayloadFactory::globalSagePrepaymentReceiptPayloadData([$quote, $payment, $paymentSplit, $sageRequest, $splitAmount]);
    $payLoadOptions = SagePayloadFactory::createAPPrepaymentReceiptPayload($sageRequest);
    $createAPPremiumPaymentReceipt = $this->postToSage300($payLoadOptions['endPoint'], $payLoadOptions['payload']);
    $sageResponse = json_decode($createAPPremiumPaymentReceipt, true);
    
    if (isset($sageResponse['PaymentsAdjustments'][0]['DocumentNumber'])) {
        // Update payment split with AP receipt ID
        $documentNumberForReceipt = $sageResponse['PaymentsAdjustments'][0]['DocumentNumber'];
        $paymentSplit->update(['sage_ap_payment_receipt_id' => $documentNumberForReceipt]);
        
        // Step 6: Ready to Post (OPEN → READY TO POST)
        $readyToPostReceiptAp = SagePayloadFactory::readyToPostAPPaymentReceiptPayload($sageResponse['BatchNumber']);
        $readyToPostResponse = $this->postToSage300($readyToPostReceiptAp['endPoint'], $readyToPostReceiptAp['payload'], 'PATCH');
        
        // Step 7: Post to General Ledger (READY TO POST → POSTED)
        $aPPostReceipts = SagePayloadFactory::postAPPaymentReceiptPayload($sageResponse['BatchNumber']);
        $postedResponse = $this->postToSage300($aPPostReceipts['endPoint'], $aPPostReceipts['payload']);
        
        return ['status' => true, 'message' => 'AP Prepayment created'];
    }
    
    return ['status' => false, 'message' => 'Document number not generated from sage'];
}

🏭 Payload Factory Methods

📍 Function Type: These are Payload Factory Methods that generate Sage 300 API request structures.

🔧 globalSagePrepaymentReceiptPayloadData() - Payload Factory Method

Static method in SagePayloadFactory that prepares and normalizes all data required for receipt creation from quote, payment, and split information.

public static function globalSagePrepaymentReceiptPayloadData($sageRequestData)
{
    [$quote, $payment, $paymentSplit, $sageRequest, $splitAmount] = $sageRequestData;
    
    // Set collection amount from payment split
    $sageRequest->collection_amount = $paymentSplit->collection_amount;
    if ($splitAmount != null) {
        $sageRequest->collection_amount = $splitAmount;
    }
    
    // Get insurance provider details
    $insuranceProvider = getInsuranceProvider($payment, $sageRequest->quoteType, $quote);
    $sageRequest->sageVenderId = $insuranceProvider?->sage_vendor_id;
    $sageRequest->insurerName = $insuranceProvider?->text;
    $sageRequest->insurerCode = $insuranceProvider?->code;
    
    // Set payment method details
    $sageRequest->sage_payment_code = $paymentSplit->payment_method;
    $sageRequest->checkNumber = $paymentSplit->check_detail;
    
    // Set advisor and customer information
    $sageRequest->advisor_id = $quote->advisor_id;
    $sageRequest->customer_id = $quote->customer_id;
    
    return $sageRequest;
}

💳 createPrepaymentReceiptPayload() - Payload Factory Method

Static method in SagePayloadFactory that creates the Sage 300 AR prepayment receipt payload structure.

public static function createPrepaymentReceiptPayload($sageRequest, $isCommissionReceipt = false)
{
    $optionalFields = self::createPrepaymentOptionalFields($sageRequest);
    $customerNumber = $sageRequest->sage_customer_number;
    $bankCode = SageEnum::BANK_CODE_INS;
    $paymentCode = SageEnum::PAYMENT_CODE_IP;
    $bankReceiptAmount = roundNumber(floatval($sageRequest->collection_amount));
    
    $payLoad = [
        'BatchRecordType' => 'CA',  // AR Receipt Batch
        'BankCode' => $bankCode,
        'ReceiptsAdjustments' => [
            [
                'BatchType' => 'CA',
                'CustomerNumber' => $customerNumber,
                'BankCode' => $bankCode,
                'BankReceiptAmount' => $bankReceiptAmount,
                'PaymentCode' => $paymentCode,
                'ReceiptTransactionType' => 'Prepayment',  // Key: Prepayment type
                'AppliedReceiptsAdjustments' => [
                    [
                        'BatchType' => 'CA',
                        'CustomerNumber' => $customerNumber,
                        'ReceiptTransactionType' => 'Prepayment',
                    ],
                ],
                'ReceiptAdjustmentOptionalField' => $optionalFields,
            ],
        ],
    ];

    return [
        'endPoint' => 'AR/ARReceiptAndAdjustmentBatches',
        'payload' => $payLoad,
        'sage_request_type' => SageEnum::SRT_CREATE_PP_REC,
        'entry_type' => SageEnum::SCT_STRAIGHT,
    ];
}

🏦 createAPPrepaymentReceiptPayload() - Payload Factory Method

Static method in SagePayloadFactory that creates the Sage 300 AP prepayment payment payload structure for vendor payments.

public static function createAPPrepaymentReceiptPayload($sageRequest)
{
    $optionalFields = self::createPrepaymentOptionalFields($sageRequest);
    $vendorNumber = $sageRequest->sageVenderId;
    $bankCode = SageEnum::BANK_CODE_INS;
    $bankReceiptAmount = roundNumber(floatval($sageRequest->collection_amount), 2);
    $entryDescription = 'CLIENT DIRECT PAYMENT TO '.$sageRequest->insurerCode;
    
    $payLoad = [
        'BatchSelector' => 'PY',  // AP Payment Batch
        'Description' => $entryDescription,
        'BankCode' => $bankCode,
        'PaymentsAdjustments' => [
            [
                'BatchType' => 'PY',
                'VendorNumber' => $vendorNumber,  // Insurance provider vendor number
                'EntryDescription' => $entryDescription,
                'PaymentTransactionType' => 'Prepayment',  // Key: Prepayment type
                'BankCode' => $bankCode,
                'TotalPrepayVendorCurrency' => $bankReceiptAmount,
                'AppliedPayments' => [
                    [
                        'BatchType' => 'PY',
                        'VendorNumber' => $vendorNumber,
                        'TransactionType' => 'PrepaymentPosted',
                    ],
                ],
                'PaymentAdjustmentOptionalField' => $optionalFields,
            ],
        ],
    ];

    return [
        'endPoint' => 'AP/APPaymentAndAdjustmentBatches',
        'payload' => $payLoad,
        'sage_request_type' => SageEnum::SRT_CREATE_AP_PP_REC,
        'entry_type' => SageEnum::SCT_STRAIGHT,
    ];
}

🔧 Receipt Processing Logic

📋 Payment Split Processing

Both AR and AP receipt creation functions process payment splits based on their payment status, focusing only on splits that have been successfully paid or captured.

✅ Processed Payment Splits

  • PAID: Payment completed successfully
  • PARTIALLY_PAID: Partial payment received
  • CAPTURED: Payment captured by gateway
  • Valid Amount: collection_amount > 0

⏭️ Skipped Payment Splits

  • Credit Approval: PaymentMethodsEnum::CreditApproval
  • Pending Status: Not yet paid or captured
  • Zero Amount: No collection amount
  • Failed Payments: Payment processing failed
// Payment split filtering logic used in both AR and AP functions
$paidPaymentSplits = $payment->paymentSplits()
    ->whereIn('payment_status_id', [
        PaymentStatusEnum::PAID,

        PaymentStatusEnum::CAPTURED

foreach ($paidPaymentSplits as $paymentSplit) {

    if ($isPaymentMethodCA) {

        continue;
    }
    
    // Process individual receipt creation
    $createPrepaymentReceiptResponse = $this->createARPrepaymentPremiumReceipt($sageRequest, $quote, $payment, $paymentSplit);
