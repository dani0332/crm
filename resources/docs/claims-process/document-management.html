☁️ Azure S3 Storage Integration

🔗 Storage Architecture

Documents are stored in Azure S3 with organized folder structure and secure access patterns:

Folder Structure:
/claims/{claim_uuid}/documents/{document_type}/{filename}
// ClaimsService::uploadDocuments() method public function uploadDocuments(array $files, string $claimUuid, int $documentTypeId): array { $uploadedFiles = []; $documentType = $this->getDocumentTypeById($documentTypeId); foreach ($files as $file) { $filename = $this->generateSecureFilename($file); $s3Path = "claims/{$claimUuid}/documents/{$documentType->value}/{$filename}"; // Upload to S3 $s3Response = Storage::disk('s3')->put($s3Path, file_get_contents($file)); if ($s3Response) { // Create database record $document = GenericDocument::create([ 'uuid' => Str::uuid(), 'model_type' => GenericModelTypeEnum::CLAIM_REQUEST, 'model_id' => $claimId, 'document_type_id' => $documentTypeId, 'file_name' => $file->getClientOriginalName(), 'file_path' => $s3Path, 'file_size' => $file->getSize(), 'mime_type' => $file->getMimeType(), 'uploaded_by' => Auth::id(), ]); $uploadedFiles[] = $document; } } return $uploadedFiles; }
Secure File Naming UUID-based filenames prevent conflicts and enhance security
Organized Storage Hierarchical folder structure by claim and document type
Metadata Tracking Complete file information stored in database
Access Control Permission-based document access with temporary URLs

🔐 Security & Access Control

🛡️ Permission-Based Access

Document access is controlled through granular permissions ensuring only authorized users can view, upload, or download claim documents.

Permission Access Level Description API Endpoints
CLAIM_DOCUMENTS_UPLOAD Upload Upload new documents to claims POST /claim/{uuid}/documents
CLAIM_DOCUMENTS_VIEW View View and download claim documents GET /claim/{uuid}/documents
CLAIM_DOCUMENTS_DELETE Delete Remove documents from claims DELETE /claim/{uuid}/documents/{id}
CLAIM_DOCUMENTS_BULK_DOWNLOAD Bulk Operations Download all documents as ZIP GET /claim/{uuid}/documents/download-all

🔒 Temporary URL Generation

For secure document access, the system generates temporary URLs with expiration times:

  • Default Expiry: 1 hour for document viewing
  • Bulk Download: 30 minutes for ZIP file access
  • Access Logging: All document access attempts are logged
  • IP Validation: Optional IP-based access restrictions
// Temporary URL generation for secure access public function generateTemporaryUrl(string $filePath, int $expiryMinutes = 60): string { return Storage::disk('s3')->temporaryUrl($filePath, now()->addMinutes($expiryMinutes)); } // Usage in ClaimsService public function getDocumentWithTemporaryUrl(int $documentId): array { $document = GenericDocument::findOrFail($documentId); // Generate temporary URL $temporaryUrl = $this->generateTemporaryUrl($document->file_path); // Log access attempt LoggerService::info('Document accessed', [ 'document_id' => $documentId, 'user_id' => Auth::id(), 'claim_uuid' => $document->model->uuid ?? null, ]); return [ 'document' => $document, 'temporary_url' => $temporaryUrl, 'expires_at' => now()->addHour()->toISOString(), ]; }

📤 File Upload Workflow

🔄 Multi-File Upload Process

POST /claim/{uuid}/documents
// ClaimsController::uploadDocuments() method public function uploadDocuments(Request $request, ClaimRequest $claim): JsonResponse { try { $request->validate([ 'files' => 'required|array|min:1|max:10', 'files.*' => 'required|file|max:10240|mimes:pdf,jpg,jpeg,png,doc,docx', 'document_type_id' => 'required|integer|exists:lookups,id', ]); $uploadedDocuments = $this->claimsService->uploadDocuments( $request->file('files'), $claim->uuid, $request->input('document_type_id') ); return response()->json([ 'success' => true, 'message' => 'Documents uploaded successfully', 'data' => GenericDocumentResource::collection($uploadedDocuments), ]); } catch (\Exception $e) { LoggerService::error(' Error uploading documents', [ 'error' => $e->getMessage(), 'claim_uuid' => $claim->uuid, 'user_id' => Auth::id(), ]); return response()->json([ 'success' => false, 'message' => 'Failed to upload documents', ], 500); } }
File Validation Size limits (10MB), format restrictions, and security checks
Batch Processing Up to 10 files per upload request
Error Handling Comprehensive error logging and user feedback
Progress Tracking Real-time upload progress with Vue.js components

📦 Bulk Operations

🗜️ ZIP Download Functionality

Claims managers can download all documents for a claim as a single ZIP file for efficient processing and archival.

GET /claim/{uuid}/documents/download-all
// ClaimsService::downloadAllDocumentsAsZip() method public function downloadAllDocumentsAsZip(string $claimUuid): Response { $claim = ClaimRequest::where('uuid', $claimUuid)->firstOrFail(); $documents = $claim->documents; if ($documents->isEmpty()) { throw new \Exception('No documents found for this claim'); } $zipFileName = "claim_{$claimUuid}_documents.zip"; $zipPath = storage_path("temp/{$zipFileName}"); // Create ZIP file $zip = new \ZipArchive(); $zip->open($zipPath, \ZipArchive::CREATE | \ZipArchive::OVERWRITE); foreach ($documents as $document) { $fileContent = Storage::disk('s3')->get($document->file_path); $zip->addFromString($document->file_name, $fileContent); } $zip->close(); // Log bulk download LoggerService::info('Bulk document download', [ 'claim_uuid' => $claimUuid, 'document_count' => $documents->count(), 'user_id' => Auth::id(), ]); return response()->download($zipPath)->deleteFileAfterSend(); }
Automatic ZIP Creation On-the-fly ZIP file generation with original filenames
Temporary Storage ZIP files created in temporary directory and auto-deleted
Comprehensive Logging All bulk operations logged for audit purposes
Permission Control Requires CLAIM_DOCUMENTS_BULK_DOWNLOAD permission

// Document analytics query example public function getDocumentAnalytics(string $period = '30 days'): array { return [ 'total_documents' => GenericDocument::where('model_type', GenericModelTypeEnum::CLAIM_REQUEST) ->where('created_at', '>=', now()->sub($period))->count(), 'documents_by_lob' => DB::table('generic_documents') ->join('claim_requests', 'generic_documents.model_id', '=', 'claim_requests.id') ->join('lookups as lob', 'claim_requests.quote_type_id', '=', 'lob.id') ->where('generic_documents.created_at', '>=', now()->sub($period)) ->groupBy('lob.value') ->selectRaw('lob.value as lob, COUNT(*) as count') ->get(), 'storage_usage' => GenericDocument::where('model_type', GenericModelTypeEnum::CLAIM_REQUEST) ->sum('file_size'), ]; }
