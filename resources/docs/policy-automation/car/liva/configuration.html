🔧 Liva Car Insurance - Configuration

Complete configuration guide for environment variables, OAuth, and feature toggles

🌍 Environment Configuration

Liva Car Automation requires several environment variables to be configured in your .env file or Laravel configuration files.

⚠ Payment Flow: Payment is PRE-CAPTURED before automation starts. The automation sends transaction details (receipt ID, auth code, transaction date, amount) to Liva API to indicate payment was already processed. No payment capture occurs during automation.

Base URL Configuration

LIVA_API_BASE_URL

Base URL for Liva API endpoints (v2 endpoints)

LIVA_API_BASE_URL=https://api.liva.insurance.com // API Endpoints (all v2): // - Auth: {LIVA_API_BASE_URL}/auth-token // - Upload: {LIVA_API_BASE_URL}/motor/documents/upload/v2 // - Issue: {LIVA_API_BASE_URL}/motor/policy/create/v2 // - Retrieve: {LIVA_API_BASE_URL}/motor/transactions/retrieve/v2

⚙️ Feature Toggles (ApplicationStorage)

Feature toggles are managed through the ApplicationStorageService and can be enabled/disabled at runtime without code changes.

Master Automation Toggle

ENABLE_LIVA_CAR_POLICY_ISSUANCE

Master toggle to enable/disable Liva Car automation globally

// Check if automation is enabled public function isPolicyIssuanceAutomationEnabled(): bool { return (bool) app(ApplicationStorageService::class) ->getValueByKey(ApplicationStorageEnums::ENABLE_LIVA_CAR_POLICY_ISSUANCE); } // Usage if (!$this->isPolicyIssuanceAutomationEnabled()) { return ['error' => 'LIVA Car Automation is disabled']; }
Default: false (disabled by default)
Type: boolean
Scope: Global - affects all quotes

Timeout Retry Toggle

ENABLE_RETRY_TIMEOUT_LIVA_CAR_POLICY_ISSUANCE

Enable retry mechanism for timeout scenarios

// Check if retry is enabled public function isPolicyIssuanceAutomationRetryEnabledForTimeout(): bool { return (bool) app(ApplicationStorageService::class) ->getValueByKey(ApplicationStorageEnums::ENABLE_RETRY_TIMEOUT_LIVA_CAR_POLICY_ISSUANCE); } // Usage in timeout detection if ($isTimeout && $this->isPolicyIssuanceAutomationRetryEnabledForTimeout()) { // Allow retry from last completed step }
Default: false (disabled by default)
Type: boolean
Purpose: Allows automatic retry when timeout is detected

API Timeout Configuration

LIVA_AUTOMATION_API_TIMEOUT

Configurable timeout in seconds for all Liva API calls

// Get timeout from ApplicationStorage $this->apiTimeout = app(ApplicationStorageService::class) ->getValueByKey(ApplicationStorageEnums::LIVA_AUTOMATION_API_TIMEOUT); // Usage in HTTP calls Http::timeout($this->apiTimeout) ->withHeaders($this->headers) ->post($url, $payload);
Default: 30 seconds (if not configured)
Type: integer (seconds)
Scope: Applied to all API calls
⚠ Important: Set appropriate timeout based on API response times. Too short may cause premature timeouts, too long may cause hanging requests.

🔐 OAuth Token Management

OAuth tokens are automatically managed with Redis caching to minimize API calls and improve performance.

Token Caching

// Cache Key const POLICY_ISSUANCE_API_ACCESS_TOKEN_KEY = 'RSA_POLICY_ISSUANCE_API_ACCESS_TOKEN'; // Token Retrieval Flow 1. Check Redis cache for existing token 2. If token exists and valid → use cached token 3. If token missing/expired → request new token 4. Cache token with expiration time from API response 5. Use token in subsequent API calls
Cache Duration: Based on expires_in from OAuth API response (default: 3599 seconds / ~60 minutes)
Cache Store: Redis
Automatic Refresh: Token is automatically refreshed when expired

Token Request Headers

// Token Request Headers Content-Type: application/x-www-form-urlencoded // Token Request Payload { 'client_id': config('constants.LIVA_CLIENT_ID'), 'client_secret': config('constants.LIVA_CLIENT_SECRET'), 'grant_type': 'client_credentials', 'scope': config('constants.LIVA_SCOPE') }

API Request Headers (After Token Retrieval)

// All API requests include these headers { 'Content-Type': 'application/json', 'Authorization': 'Basic {LIVA_BASIC_AUTH}', 'PartnerId': '{LIVA_PARENT_ID}', 'location': '{LIVA_LOCATION}', 'Authentication': 'Bearer {access_token}', 'SubscriptionKey': '{LIVA_SUBSCRIPTION_KEY}' }

🔧 Runtime Configuration

Configuration values can be updated at runtime through the ApplicationStorageService without requiring code changes or deployments.

Updating Configuration Values

// Example: Enable automation app(ApplicationStorageService::class)->setValueByKey( ApplicationStorageEnums::ENABLE_LIVA_CAR_POLICY_ISSUANCE, true ); // Example: Set API timeout app(ApplicationStorageService::class)->setValueByKey( ApplicationStorageEnums::LIVA_AUTOMATION_API_TIMEOUT, 60 // 60 seconds ); // Example: Enable timeout retry app(ApplicationStorageService::class)->setValueByKey( ApplicationStorageEnums::ENABLE_RETRY_TIMEOUT_LIVA_CAR_POLICY_ISSUANCE, true );
Configuration Storage: Values are stored in the application_storage database table and cached for performance.

📊 Configuration Checklist

Use this checklist to ensure all configuration is properly set up:

Environment Variables

  • ☐ LIVA_API_BASE_URL configured
  • ☐ LIVA_CLIENT_ID configured
  • ☐ LIVA_CLIENT_SECRET configured
  • ☐ LIVA_SCOPE configured
  • ☐ LIVA_BASIC_AUTH configured
  • ☐ LIVA_PARENT_ID configured
  • ☐ LIVA_LOCATION configured
  • ☐ LIVA_SUBSCRIPTION_KEY configured

ApplicationStorage Configuration

  • ☐ ENABLE_LIVA_CAR_POLICY_ISSUANCE set (true/false)
  • ☐ LIVA_AUTOMATION_API_TIMEOUT configured (seconds)
  • ☐ ENABLE_RETRY_TIMEOUT_LIVA_CAR_POLICY_ISSUANCE set (true/false)

Infrastructure

  • ☐ Redis configured and accessible for token caching
  • ☐ Azure storage configured for document storage
  • ☐ Database connection configured

🔍 Configuration Validation

The system validates configuration before executing automation steps.

// Configuration validation in executeSteps() public function executeSteps($process) { // Get OAuth token (validates OAuth config) $this->getAccessToken(); // Check if automation is enabled if (!$this->isPolicyIssuanceAutomationEnabled()) { return ['error' => 'LIVA Car Automation is disabled']; } // Check quote-level automation toggle if (!$quote->isQuotePolicyIssuanceAutomationEnabled()) { return ['error' => 'LIVA Car Quote Policy Issuance Automation is disabled']; } // Continue with automation... }
⚠ Configuration Errors: If configuration is missing or invalid, the automation will fail with appropriate error messages. Check logs for detailed error information.
