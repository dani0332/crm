❓ What is Liva Car Automation?

The Liva Car Insurance Automation system is a comprehensive, production-ready solution that automates the complete policy issuance workflow with Liva Insurance Company (RSA). Built using a modular, service-oriented architecture, it handles everything from document upload to final booking with comprehensive audit trails, OAuth authentication, and robust error handling.

💡 System Highlights

Liva Car Automation eliminates manual processing and integrates seamlessly with Liva's APIs:

✓ 4-Step Automation Workflow with state management and progress tracking
✓ OAuth 2.0 Authentication with Redis token caching
✓ Pre-captured Payment - Payment already authorized before automation starts
✓ 3 API Endpoints for document upload (v2), policy creation (v2), and document retrieval (v2)
✓ Double Base64 Decoding for document retrieval (CRITICAL - Liva API requirement)
✓ One-by-One Document Retrieval - Documents fetched individually with toggle flags
✓ Timeout Detection - Detects null status responses and updates to TIMEOUT_STATUS
✓ Comprehensive Logging at every step using LoggerService
✓ Pre-validation before API calls to prevent unnecessary failures
✓ Azure Storage Integration for document management
✓ Sage ERP Integration for final booking process
✓ RTA Status Updates - Updates rta_upload_status when Policy Certificate uploaded

💳 Pre-Automation Payment Capture

🔑 Critical Prerequisite Step

Auto-capture executes BEFORE automation workflow starts during the split payment approval process:

✓ When: During SplitPaymentService->processSplitPaymentApprove() execution (background job CcPaymentProcess)
✓ What: Captures authorized payments via Marshall/Tap API using CRUDService->capturePayment()
✓ Code Location: SplitPaymentService.php lines 770-792, 1475-1487
✓ Marshall API: Creates PaymentAction record with action_type: 'CAPTURE' and amount
✓ Retry Logic: Up to 3 attempts with 1-second delay between retries

Success: If capture succeeds → Automation workflow is scheduled via createPolicyIssuanceAutomation()
Failure: If capture fails → handleAutomationError() sets AUTO_CAPTURE_FAILED_STATUS_ID and allocates to team (prevents automation from starting)

This is why documentation refers to "pre-captured" payments - the payment must be successfully captured before any automation steps can execute.

🔄 Complete Automation Workflow

Sequential 4-step automation process with state management and error handling at each stage

1️⃣ Upload Documents

Upload required documents (Driving License, Emirates ID, Registration Card) to Liva

2️⃣ Issue Policy

Create policy with Liva API using quote and payment details

3️⃣ Upload Policy Documents

Retrieve policy documents from Liva and upload to IMCRM

4️⃣ Book Policy

Finalize booking with Sage integration
