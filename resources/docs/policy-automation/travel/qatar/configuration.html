🌍 Environment Configuration

Qatar Travel automation requires several environment variables to be configured. These are typically stored in your .env file and accessed via Laravel's configuration system.

Required Environment Variables

Variable Name Description Example Value Required
ALLIANCE_API_BASE_URL Base URL for Qatar API endpoints https://api.alliance.ae ✅ Yes
ALLIANCE_AGENCY_ID Qatar agency identifier for authentication AGENCY123 ✅ Yes
ALLIANCE_AGENCY_CODE Qatar agency code for authentication CODE456 ✅ Yes

Configuration File Structure

These variables are accessed via Laravel's config system. Add them to config/constants.php:

'ALLIANCE_API_BASE_URL' => env('ALLIANCE_API_BASE_URL'), 'ALLIANCE_AGENCY_ID' => env('ALLIANCE_AGENCY_ID'), 'ALLIANCE_AGENCY_CODE' => env('ALLIANCE_AGENCY_CODE'),
💡 Best Practice Always use env() function in configuration files, never directly in application code. Access configuration values using config('constants.ALLIANCE_API_BASE_URL').

🎛️ Feature Toggles

Feature toggles allow you to enable or disable Qatar Travel automation at runtime without code changes. These are stored in the application_storage table and accessed via ApplicationStorageService.

Available Feature Toggles

Storage Key Description Default Value Type
ENABLE_QATAR_TRAVEL_POLICY_ISSUANCE Master toggle to enable/disable Qatar Travel automation false boolean
ENABLE_RETRY_TIMEOUT_QATAR_TRAVEL_POLICY_ISSUANCE Enable retry mechanism for timeout errors false boolean

Feature Toggle Usage

// Check if automation is enabled public function isPolicyIssuanceAutomationEnabled(): bool { return app(ApplicationStorageService::class) ->getValueByKey(ApplicationStorageEnums::ENABLE_QATAR_TRAVEL_POLICY_ISSUANCE); } // Check if retry is enabled public function isPolicyIssuanceAutomationRetryEnabledForTimeout(): bool { return app(ApplicationStorageService::class) ->getValueByKey(ApplicationStorageEnums::ENABLE_RETRY_TIMEOUT_QATAR_TRAVEL_POLICY_ISSUANCE); }
⚠️ Important When ENABLE_QATAR_TRAVEL_POLICY_ISSUANCE is disabled, the automation will not execute, but it will log that automation is disabled. This allows you to safely disable automation without breaking the system.

⚙️ Runtime Configuration

Some configuration values are retrieved at runtime from ApplicationStorage, allowing changes without code deployment.

VAT Configuration

The VAT value is retrieved from ApplicationStorage at runtime:

public function __construct() { $this->vat = app(ApplicationStorageService::class) ->getValueByKey(ApplicationStorageEnums::VAT_VALUE); }
VAT Calculation The VAT value is used to calculate VAT-applicable prices and VAT amounts from premium values. This allows VAT rate changes without code deployment.

🔌 API Configuration

HTTP Client Configuration

The HTTP client is configured with the following settings:

Base URL {ALLIANCE_API_BASE_URL}/api

Base URL with /api suffix

Timeout 20 seconds

Fixed timeout for all requests

Content-Type application/json

Request content type

Authentication Configuration

Authentication parameters are merged into every request payload:

private mixed $authParam; public function __construct() { $this->authParam = [ 'agency_id' => config('constants.ALLIANCE_AGENCY_ID'), 'agency_code' => config('constants.ALLIANCE_AGENCY_CODE'), ]; } private function qatarHttpCall($endPoint, $param) { $payload = array_merge($this->authParam, $param); // ... rest of HTTP call }

🔄 Retry Configuration

Document Generation Retry

Step 3 (Upload Policy Documents) includes a retry mechanism for document generation delays:

public function fetchAndUploadDocument($quote, $travelType): array { $maxRetries = 5; $retryDelay = 10; // seconds $retryCount = 0; do { sleep($retryDelay); $policyDocuments = $this->qatarHttpCall($endPoint, $payload); if ($policyDocuments->failed() && str_contains($response->errors[0], 'Policy documents are still generating')) { $retryCount++; } else { break; } } while ($retryCount < $maxRetries); }
Parameter Value Description
maxRetries 5 Maximum number of retry attempts
retryDelay 10 seconds Delay between retry attempts
Retry Condition "Policy documents are still generating" Error message that triggers retry
Retry Logic The system only retries when the error message contains "Policy documents are still generating". Other errors will fail immediately without retry.

✈️ Travel Type Configuration

Travel Type Determination

The system automatically determines travel type based on quote's direction_code:

// Default to Inbound $travelType = TravelQuoteEnum::QATAR_IN_BOUND; $directionCode = $quote->direction_code; // Check if Outbound if ($directionCode === TravelQuoteEnum::TRAVEL_UAE_OUTBOUND) { $travelType = TravelQuoteEnum::QATAR_OUT_BOUND; }
Direction Code Travel Type API Endpoint Suffix
TRAVEL_UAE_OUTBOUND Outbound outbound
Other values Inbound inbound

Multi-Trip Coverage Configuration

Special handling for multi-trip inbound policies:

public function calculateCoverDaysForExpiryDate($quote, $travelType): mixed { $coverDays = $quote->days_cover_for; $isInboundLead = $travelType === TravelQuoteEnum::QATAR_IN_BOUND; $isMultiTripLead = $quote->coverage_code === TravelQuoteEnum::COVERAGE_CODE_MULTI_TRIP; if ($isInboundLead && $isMultiTripLead) { $coverDays = 180; // Fixed 180 days for multi-trip inbound } return $coverDays; }
Multi-Trip Limit Multi-trip inbound policies have a fixed cover period of 180 days, regardless of the days_cover_for value. Other travel types use days_cover_for from the quote.

📄 Document Configuration

Document Type Mapping

Qatar document names are mapped to IMCRM document codes:

Qatar Document Name IMCRM Document Code Quote Type ID
"Policy Tax Invoice" TRAVEL_TAX_INVOICE Travel
"Certificate of Insurance" TRAVEL_POLICY_SCHEDULE Travel
Buyer Tax Invoice TRAVEL_TAX_INVOICE_RAISE_BY_BUYER Travel

Document Storage Configuration

Documents are stored in Azure Storage with the following path structure:

$filePathAzure = 'documents/' . ucwords(self::TYPE) . '/' . $fileNameAzure; // Example: documents/Travel/uniqueid_quoteuuid_documentname.pdf
Azure Storage Documents are stored in the azureIMPrivate disk. Ensure Azure Storage credentials are configured in config/filesystems.php.

📧 Contact Information Configuration

Static Contact Details

For privacy protection, static contact details are used instead of customer information:

$payload = [ // ... other fields 'email' => 'happiness@support.insurancemarket.ae', // Static email 'mobile' => '971502245943', // Static mobile 'agency_reference' => 'asc', ];
Privacy Protection Customer contact details are not shared with Qatar. Static contact information is used to protect customer privacy while maintaining API compatibility.

🔍 Troubleshooting

Common Configuration Issues

Issue Possible Cause Solution
Authentication failures Invalid agency_id or agency_code Verify environment variables match Qatar credentials
API timeout errors Network issues or slow API response Check network connectivity; consider increasing timeout
Document upload failures Azure Storage not configured Verify Azure Storage credentials in config/filesystems.php
Automation not running Feature toggle disabled Check ApplicationStorage for ENABLE_QATAR_TRAVEL_POLICY_ISSUANCE
Document mapping errors Document type not found in IMCRM Verify document types exist in DocumentType table for Travel quote type
