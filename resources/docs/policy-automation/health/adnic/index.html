❓ What is ADNIC Health Automation?

The ADNIC Health Insurance Automation system is a comprehensive, production-ready solution that automates the complete policy issuance workflow with ADNIC Insurance Company. Built using a modular, service-oriented architecture with 10+ specialized services, it handles everything from policy creation to final booking with comprehensive audit trails and error handling.

💳 Pre-Automation Payment Capture

🔑 Critical Prerequisite Step

Auto-capture executes BEFORE automation workflow starts during the split payment approval process:

✓ When: During SplitPaymentService->processSplitPaymentApprove() execution (background job CcPaymentProcess)
✓ What: Captures authorized payments via Marshall/Tap API using CRUDService->capturePayment()
✓ Code Location: SplitPaymentService.php lines 770-792, 1475-1487
✓ Marshall API: Creates PaymentAction record with action_type: 'CAPTURE' and amount
✓ Retry Logic: Up to 3 attempts with 1-second delay between retries

Success: If capture succeeds → Automation workflow is scheduled via createPolicyIssuanceAutomation()
Failure: If capture fails → handleAutomationError() sets AUTO_CAPTURE_FAILED_STATUS_ID and allocates to team (prevents automation from starting)

This is why documentation refers to "pre-captured" payments - the payment must be successfully captured before any automation steps can execute.
