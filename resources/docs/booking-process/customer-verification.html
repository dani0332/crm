👤 Customer Verification Process

Comprehensive guide to Sage 300 customer verification and creation

🎯 Overview

The customer verification process is a critical component of the Sage 300 ERP integration that ensures every customer exists in the Sage system before any financial transactions are processed. This automated system handles both individual customers and business entities with intelligent duplicate prevention and error handling.

🔑 Key Benefits

Automatic customer creation, duplicate prevention, polymorphic entity support, comprehensive error handling, and full audit trail logging ensure data integrity across the entire insurance platform.

📋 Process Components Explained

🔍 Customer Lookup Phase

  • Searches existing customers in local database
  • Checks Sage 300 system for customer existence
  • Uses unique customer identifiers for matching
  • Handles both individual and business entities

✅ Validation & Creation Phase

  • Validates customer data completeness
  • Creates new customer records when not found
  • Applies business rules for customer numbering
  • Ensures data consistency across systems

🔄 Synchronization Phase

  • Updates local database with Sage customer numbers
  • Maintains referential integrity
  • Logs all operations for audit trail
  • Handles error scenarios gracefully

🔄 Process Workflow

1

Customer Lookup

Check if customer exists in Sage 300 using GET request to AR/ARCustomers endpoint

2

Validation Check

Process API response and handle RecordNotFound errors for new customer creation

3

Customer Creation

Create new customer in Sage if not found, using appropriate payload structure

4

Database Sync

Update local database with Sage customer number and log all API interactions

🛠️ Technical Implementation

📍 Primary Method: verifySageCustomer()

Located in app/Services/SageApiService.php, this method orchestrates the entire customer verification and creation process. 

public function verifySageCustomer($customerId, $data = null, $logModal = null, $totalSteps = 4, $authUserId = null)
{
    LoggerService::info(self::class.' fn: '.__FUNCTION__.' - Sage Customer verification process start');

    $customer = Customer::find($customerId);
    $quoteEntityMapping = QuoteRequestEntityMapping::with('entity')
        ->where(['quote_type_id' => $data['quoteTypeId'], 'quote_request_id' => $data['id']])
        ->first();

    $quoteEntity = $quoteEntityMapping?->entity;
    $payLoadOptions = SagePayloadFactory::createCustomerPayload($customer, $quoteEntity);

    $sageCustomerFromDB = ($quoteEntity) ? $quoteEntity?->sage_customer_number : $customer?->sage_customer_number;
    $customerNumber = $sageCustomerFromDB ?? $payLoadOptions['customerNumber'];

    // Check if customer exists in Sage
    $urlGetCustomer = SageEnum::END_POINT_AR_CUSTOMER."('".$customerNumber."')";
    $customerResponse = json_decode($this->postToSage300($urlGetCustomer, [], 'GET'), true);

    if ($customerResponse && isset($customerResponse['CustomerNumber'])) {
        // Customer exists
        LoggerService::info('Customer already exists on Sage - Customer Code: '.$customerNumber);
        $sageCustomerNumber = $customerResponse['CustomerNumber'];
    } else {
        // Create new customer
        $customerResponse = json_decode($this->postToSage300($payLoadOptions['endPoint'], $payLoadOptions['payload']), true);
        $sageCustomerNumber = $customerResponse['CustomerNumber'];
    }

    return $sageCustomerNumber;
}

🏭 Customer Payload Factory

The SagePayloadFactory::createCustomerPayload() method generates the appropriate payload structure based on customer type (individual vs business entity).

👤 Individual Customer Payload

  • Customer Number: P{customer_id}
  • Customer Name: First + Last Name
  • Group Code: PHI (Personal Health Insurance)
  • Endpoint: AR/ARCustomers

🏢 Business Entity Payload

  • Customer Number: C{customer_id}
  • Customer Name: Company Name
  • Group Code: PHC (Personal Health Company)
  • Endpoint: AR/ARCustomers
public static function createCustomerPayload($customer, $entity)
{
    $entryType = SageEnum::SCT_STRAIGHT;

    if ($entity) {
        // Business Entity
        $payLoad = [
            'CustomerNumber' => 'C'.$customer->id,
            'CustomerName' => $entity?->company_name,
            'GroupCode' => 'PHC',
        ];
    } else {
        // Individual Customer
        $payLoad = [
            'CustomerNumber' => 'P'.$customer->id,
            'CustomerName' => $customer->insured_first_name.' '.$customer->insured_last_name,
            'GroupCode' => 'PHI',
        ];
    }

    return [
        'endPoint' => SageEnum::END_POINT_AR_CUSTOMER,
        'payload' => $payLoad,
        'customerNumber' => $payLoad['CustomerNumber'],
        'sage_request_type' => SageEnum::SRT_CREATE_CUSTOMER,
        'entry_type' => $entryType,
    ];
}

🚨 Error Handling & Edge Cases

🔍 Common Error Scenarios

RecordNotFound Error

  • Triggers automatic customer creation
  • Normal flow for new customers
  • Logged as INFO level message
  • Continues with creation process

Customer Creation Failure

  • Logs detailed error information
  • Updates sage_api_logs with FAIL status
  • Returns false to halt process
  • Includes payload and response data

Network/API Timeouts

  • 80-second timeout configuration
  • Automatic retry mechanisms
  • Comprehensive error logging
  • Graceful failure handling

Duplicate Customer Handling

  • Checks existing sage_customer_number
  • Skips API call if already exists
  • Updates local database if missing
  • Maintains data consistency

🔄 Detailed Process Flow Explanation

📍 Step 1: Customer Data Retrieval

// Retrieve customer from database
$customer = Customer::find($customerId);

// Check for business entity mapping
$quoteEntityMapping = QuoteRequestEntityMapping::with('entity')
    ->where(['quote_type_id' => $data['quoteTypeId'], 'quote_request_id' => $data['id']])
    ->first();

$quoteEntity = $quoteEntityMapping?->entity;

Explanation: The process starts by retrieving the customer record from the local database using the provided customer ID. It then checks if there's a business entity associated with this quote by looking up the quote_request_entity_mappings table. This determines whether we're dealing with an individual customer or a business entity.

📍 Step 2: Sage Customer Number Resolution

// Determine existing Sage customer number
$sageCustomerFromDB = ($quoteEntity) ?
    $quoteEntity?->sage_customer_number :
    $customer?->sage_customer_number;

// Generate customer number if not exists
$customerNumber = $sageCustomerFromDB ?? $payLoadOptions['customerNumber'];

Explanation: The system checks if a Sage customer number already exists in the local database. For business entities, it checks the entities.sage_customer_number column. For individual customers, it checks customers.sage_customer_number. If no existing number is found, it uses the generated customer number from the payload factory (P{customer_id} for individuals, C{customer_id} for companies).

📍 Step 3: Sage System Verification

// Check if customer exists in Sage 300
$urlGetCustomer = SageEnum::END_POINT_AR_CUSTOMER."('".$customerNumber."')";
$customerResponse = json_decode($this->postToSage300($urlGetCustomer, [], 'GET'), true);

if ($customerResponse && isset($customerResponse['CustomerNumber'])) {
    // Customer exists in Sage
    $sageCustomerNumber = $customerResponse['CustomerNumber'];
}

Explanation: The system makes a GET request to Sage 300's AR/ARCustomers endpoint to verify if the customer already exists in the ERP system. The endpoint format is AR/ARCustomers('CustomerNumber'). If the customer exists, Sage returns the customer details including the CustomerNumber.

📍 Step 4: Customer Creation (if needed)

$responseError = isset($customerResponse['error']['code']) ? $customerResponse['error']['code'] : false;
if ($responseError && $responseError == SageEnum::ERROR_RECORD_NOT_FOUND) {
    // Customer not found, create new customer
    $customerResponse = json_decode($this->postToSage300($payLoadOptions['endPoint'], $payLoadOptions['payload']), true);

    if ($customerResponse && isset($customerResponse['CustomerNumber'])) {
        $sageCustomerNumber = $customerResponse['CustomerNumber'];
    }
}

Explanation: If Sage returns a "RecordNotFound" error, it means the customer doesn't exist in Sage 300. The system then creates a new customer by making a POST request to AR/ARCustomers with the customer payload. The payload contains CustomerNumber, CustomerName, and GroupCode based on customer type.

📍 Step 5: Database Synchronization

if (!$sageCustomerFromDB && ($customerResponse && isset($customerResponse['CustomerNumber']))) {
    if ($quoteEntity) {
        $quoteEntity->sage_customer_number = $sageCustomerNumber;
        $quoteEntity->save();
    } elseif ($customer) {
        $customer->sage_customer_number = $sageCustomerNumber;
        $customer->save();
    }
}

Explanation: After successful customer creation or verification in Sage, the system updates the local database with the Sage customer number. For business entities, it updates the entities.sage_customer_number column. For individual customers, it updates the customers.sage_customer_number column. This ensures future lookups can find the existing Sage reference without making unnecessary API calls.

📝 Logging & Audit Trail

🗂️ Comprehensive Logging System

Every customer verification operation is logged in the sage_api_logs table with detailed information about the request, response, and outcome. This provides a complete audit trail for troubleshooting and compliance purposes.

📊 Log Entry Creation Process

$this->logSageApiCall([
    'endPoint' => SageEnum::END_POINT_AR_CUSTOMER,
    'payload' => $payLoadOptions,
], $customerResponse, $logModal, $logModal, 1, $totalSteps, SageEnum::STATUS_SUCCESS, $authUserId);

// Log entry includes:
// - user_id: Who initiated the process
// - section_id/section_type: Quote being processed
// - model_id/model_type: Customer/Entity record

// - sage_request_type: CREATE_CUSTOMER
// - sage_payload: JSON of request data
// - response: JSON of Sage response
// - status: success or fail
