# Cyber LOB Routes Documentation

## Overview

This document lists all routes used by the Cyber Insurance LOB, including their exact URLs, route names, controllers, and methods.

## Route Prefix

All Cyber resource routes are under the `personal-quotes` prefix group.

**Code Reference**: `routes/web.php:305-307`

## Resource Routes

### Lead Management Routes

**Route Definition**:

```php
Route::prefix('personal-quotes')->group(function () {
    Route::resource('/cyber', CyberQuoteController::class)
        ->names(generateRouteNames('cyber-quotes'));
});
```

**Generated Routes**:

| Method | URL                                  | Route Name            | Controller Method              | Purpose              |
| ------ | ------------------------------------ | --------------------- | ------------------------------ | -------------------- |
| GET    | `/personal-quotes/cyber`             | `cyber-quotes-list`   | `CyberQuoteController@index`   | List all Cyber leads |
| GET    | `/personal-quotes/cyber/create`      | `cyber-quotes-create` | `CyberQuoteController@create`  | Show create form     |
| POST   | `/personal-quotes/cyber`             | `cyber-quotes-store`  | `CyberQuoteController@store`   | Create new lead      |
| GET    | `/personal-quotes/cyber/{uuid}`      | `cyber-quotes-show`   | `CyberQuoteController@show`    | Show lead details    |
| GET    | `/personal-quotes/cyber/{uuid}/edit` | `cyber-quotes-edit`   | `CyberQuoteController@edit`    | Show edit form       |
| PUT    | `/personal-quotes/cyber/{uuid}`      | `cyber-quotes-update` | `CyberQuoteController@update`  | Update lead          |
| DELETE | `/personal-quotes/cyber/{uuid}`      | `cyber-quotes-delete` | `CyberQuoteController@destroy` | Delete lead          |

**Code Reference**:

- Route definition: `routes/web.php:305-307`
- Route name generator: `app/helpers/Helper.php:479-491`
- Controller: `app/Http/Controllers/V2/CyberQuoteController.php`

## Available Plans Route

**Route Definition**:

```php
Route::post('/{quoteType}/available-plans/{id}', [CentralController::class, 'loadAvailablePlans']);
```

**Route Details**:

- **Method**: POST
- **URL**: `/quotes/cyber/available-plans/{uuid}` (route is under `quotes/` prefix group)
- **Route Name**: None (direct route)
- **Controller**: `CentralController@loadAvailablePlans`
- **Parameters**:
  - `{quoteType}` = 'cyber'
  - `{id}` = Lead UUID

**Purpose**: Fetch available Cyber Insurance plans from KEN API

**Code Reference**:

- Route definition: `routes/web.php:625`
- Controller method: `app/Http/Controllers/V2/CentralController.php:loadAvailablePlans()`
- Service routing: `app/Services/CentralService.php:340-342`
- Frontend usage: `resources/js/inertia/Pages/CyberQuote/Show.vue:369-399`

## Route Naming Convention

Cyber routes follow the pattern: `cyber-quotes-{action}`

Generated by `generateRouteNames('cyber-quotes')`:

- `index` → `cyber-quotes-list`
- `create` → `cyber-quotes-create`
- `store` → `cyber-quotes-store`
- `show` → `cyber-quotes-show`
- `edit` → `cyber-quotes-edit`
- `update` → `cyber-quotes-update`
- `destroy` → `cyber-quotes-delete`

## Middleware

All Cyber routes are protected by:

- Authentication middleware (default Laravel auth)
- Permission middleware (specific to each route)

**Permission Checks**:

- List: `CYBER_QUOTES_LIST` or `VIEW_ALL_LEADS`
- Create: `CYBER_QUOTES_CREATE`
- Edit/Update: `CYBER_QUOTES_EDIT` or `VIEW_ALL_LEADS`
- Show: `CYBER_QUOTES_SHOW` or `VIEW_ALL_LEADS`

**Code Reference**: `app/Http/Controllers/V2/CyberQuoteController.php:19-26`
